# Nahla's Portfolio

A React + Vite portfolio starter with a muted-blue scrapbook/editorial look and cursor-reactive parallax layers.

## Run locally

1. Install Node.js LTS from https://nodejs.org if you don't have it.
2. Extract this folder.
3. Open the extracted `nahla-portfolio` folder in VS Code.
4. Open Terminal → New Terminal.
5. Run:

   ```bash
   npm install
   npm run dev
   ```

6. Open the local URL printed in the terminal (usually http://localhost:5173).

## Customize

- Replace `public/nahla-portrait.png` with another portrait using the same filename.
- Edit project names, descriptions, technologies and links in `src/main.jsx`.
- Update the email address and social links in `src/main.jsx`.
- Colors, spacing and layouts are in `src/style.css`.

## Notes

- The cursor-parallax movement is implemented in React. On touch devices, the layout remains usable without a mouse.
- Project metrics/descriptions should be checked and updated before publishing.
- The Contact section uses an email link, not a backend contact form.
- The generated portrait is an illustration, not a photograph.
